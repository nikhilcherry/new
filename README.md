# Tic Tac Toe

A two-player Tic Tac Toe game in plain HTML, CSS and JavaScript. No build step, no dependencies.

- Click a cell to place X or O in turn.
- The game detects all eight winning lines and a draw, and a restart button resets the board.

```bash
# open index.html in a browser, or:
python3 -m http.server 8000     # http://localhost:8000
```

Files: `index.html` (board), `style.css` (layout), `script.js` (game state and win check).
